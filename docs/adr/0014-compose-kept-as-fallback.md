# 0014 — docker-compose kept as a lightweight fallback

**Decision.** `deploy/compose` stays, fed by the same `deploy/shared` rules and dashboard as the
Kubernetes platform (both generated by `scripts/gen_observability.py`).

**Why.** ~1.5 GB instead of ~4 GB when the cluster is not needed; a 30-second smoke environment
for CI; the `stack` tests run unchanged against both (only URLs differ). Kubernetes is the main
target.
