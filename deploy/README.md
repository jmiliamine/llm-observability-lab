# deploy

Everything needed to run the lab, in two flavours that share the same alert rules, dashboard
and database setup.

```
deploy/
├── k8s/          the main target: a k3d cluster
│   ├── k3d.yaml      the cluster itself (2 nodes, a registry, ports)
│   ├── platform/     what a platform team owns: monitoring, tracing, logs, the Gateway
│   └── app/          what the app team owns: the RAG API, PostgreSQL, the ingest job
├── compose/      the light version: the same backends with Docker Compose, app on your machine
└── shared/       used by both: SLO rules, the Grafana dashboard, the database init script
```

## k8s/platform

Installed by `task platform:up` from pinned Helm charts (versions in `Taskfile.yml`).

| File | What it sets up |
|---|---|
| `namespaces.yaml` | `monitoring`, `observability`, `gateway` |
| `values/kube-prometheus-stack.yaml` | Prometheus Operator, Prometheus, Grafana, Alertmanager |
| `values/loki.yaml`, `values/tempo.yaml` | logs and traces |
| `values/otel-collector.yaml` | the Collector: receives OTLP, adds pod metadata, fans out |
| `traefik-gateway.yaml`, `gateway.yaml` | Traefik as Gateway API implementation, the shared Gateway and the UI routes |
| `generated/` | the dashboard and alert rules as Kubernetes objects. Written by `task gen`, never edited by hand |

## k8s/app

Plain manifests assembled with Kustomize. `base/` is the app; an overlay picks the image and
the models.

| Path | What it is |
|---|---|
| `base/deployment.yaml`, `service.yaml`, `httproute.yaml`, `pdb.yaml` | the API: two replicas behind the Gateway |
| `base/postgres.yaml` | PostgreSQL + pgvector, its Service and its NetworkPolicy |
| `base/ingest-cronjob.yaml` | the job that (re)builds the index from the data lake |
| `base/purge-cronjob.yaml` | the nightly job that deletes idle conversations |
| `base/datalake.yaml` | the data lake: the host folder of notes as a read-only volume, for the ingest job only |
| `base/configmap.yaml` | all the non-secret settings |
| `base/ollama.yaml` | a cluster name for Ollama running on the host |
| `base/networkpolicy.yaml`, `namespace.yaml`, `serviceaccount.yaml` | isolation and pod security |
| `overlays/local` | real models through Ollama |
| `overlays/fake` | built-in fake models, no GPU needed |

`task app:build` also writes `overlays/_build/`, a git-ignored overlay that pins the image tag
of your last build.

## compose

`docker-compose.yml` starts Prometheus, Tempo, Loki, Grafana, the Collector and PostgreSQL. The
other files are their configuration. Every port is bound to 127.0.0.1.

## shared

| File | Used by |
|---|---|
| `prometheus/rag-slo.yml` | Compose mounts it; `task gen` wraps it in a `PrometheusRule` for the cluster |
| `grafana/llm-rag-overview.json` | the dashboard, generated by `scripts/gen_observability.py` |
| `postgres/init-obslab.sh` | first-start script: the pgvector extension and the two database roles |
